# kachastepien.com

Portfolio of **Katarzyna Stępień**, Product Designer (UX/UI) & Researcher in Warsaw, working on digital health, AI and data.

**[kachastepien.com](https://kachastepien.com)** · [LinkedIn](https://www.linkedin.com/in/kachastepien)

Two perspectives in one site: product design and data science.

Hand-built static site (HTML, CSS and vanilla JS, images in `assets/`), hosted on GitHub Pages.

Project pages live in `work/<slug>/` and are generated from `scripts/build_projects.py` (`python3 scripts/build_projects.py`). Shared styles are in `assets/site.css`.
